## What it does

`main.ts` writes a single original one-line joke about crypto and trading
life to `/output/entry.txt` — UTF-8, one line, under 200 characters. A judge
model reads the entries two at a time and picks the funniest.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).

## The joke

> I told my wife I bought the dip. She asked which one — the $60k dip, the $50k dip, or the one that ate our honeymoon fund?
